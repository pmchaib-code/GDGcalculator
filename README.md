# 🧮 GDG Algiers — Precision Calculator

A modern, production-ready, interactive web calculator built with pure **Vanilla HTML, CSS, and JavaScript**. Designed as a candidate task submission for **GDG Algiers (Google Developer Groups Algiers)**.

### 🌐 Live Demo

- 🔗 **Live Demo: https://pmchaib-code.github.io/GDGcalculator/
---

## 🌟 Key Features

- **Strict Operator Precedence (BODMAS/PEMDAS):** Handles complex expressions accurately according to standard mathematical rules (e.g., `2 + 3 * 4 = 14`).
- **Google & GDG Algiers Aesthetic:** Tailored visual design featuring Google’s classic color palette, customized GDG Algiers logo brackets (`</>`), smooth glassmorphic UI, and dynamic ambient background lighting.
- **Full Keyboard Support:** Complete mapping for numbers, operators, `Enter`, `Backspace`, `Escape`, and custom keypress visual feedback animations.
- **Dual-Line Display System:** Clear layout separating the active/historical expression from the current input and calculated result.
- **Interactive History Log:** Sliding drawer panel saving past calculations with time tracking and quick-restore capability.
- **Responsive & Dark/Light Mode:** Seamless experience across desktop and mobile devices with smooth theme transitions.
- **Tactile Audio Feedback:** Built-in Web Audio API click sound effects for keypresses (with toggle controls).

---

## 🛠️ Tech Stack & Constraints

- **HTML5:** Semantic document structure.
- **CSS3:** Custom CSS variables, flexbox/grid layout, and smooth micro-animations.
- **Vanilla JavaScript (ES6+):** Pure JS logic built without external libraries or frameworks (No React, Vue, or build tools).
